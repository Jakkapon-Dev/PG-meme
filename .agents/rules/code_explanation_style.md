# Code & Syntax Explanation Style Guidelines

When explaining code snippets, frameworks, or technical concepts (especially in Thai):

1. **Syntax Mapping**: Explicitly point out the core structural JavaScript/programming elements in the code:
   - **Function (ฟังก์ชัน)**: Operations or commands expecting inputs.
   - **Argument (อาร์กิวเมนต์)**: Inputs passed into function parentheses `()`.
   - **Array (อาร์เรย์)**: Collections/lists wrapped in brackets `[...]`.
   - **Object (ออบเจกต์)**: Key-value containers wrapped in curly braces `{...}`.

2. **Cause-and-Effect Narrative ("ทำให้เกิด...")**:
   - Walk through the code sequentially.
   - For each structural piece, explain its practical result on the application state, UI, or routing using the phrasing **"ทำให้เกิด..."**.

3. **Mental Model & Analogies**:
   - Use clear real-world metaphors (e.g., house & rooms, picture frame, tools, GPS).
